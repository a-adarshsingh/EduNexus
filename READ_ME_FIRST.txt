EDUNEXUS - kaise chalayein (Windows 11)

1. ZIP ko poora Extract karein (right click -> Extract All). ZIP ke andar se mat chalayein.
2. START_EDUNEXUS.bat par DOUBLE-CLICK karein.
   (Agar Windows "protected your PC" dikhaye: More info -> Run anyway.)
3. Pehli baar ye apne aap Python 3.12, Ollama aur AI model install karega. Internet chahiye,
   aur 10-20 minute lag sakte hain. Beech mein bole to "window band karke dobara double-click karein".
4. Browser khud khulega: http://localhost:8000
   Dobara chalane par sirf START_EDUNEXUS.bat double-click karein.
5. Band karne ke liye black window band kar dein.

Voice ke liye Chrome ya Edge use karein.

Agar "Application Control policy has blocked this file" error aaye:
Ye Windows ki Smart App Control hai. Is version mein compiled files hata di gayi hain,
isliye ab nahi aana chahiye. Phir bhi aaye to error ka poora text bhej dein.
